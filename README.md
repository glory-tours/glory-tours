# Glory Tours website — updated build

Responsive bilingual English/Arabic website with:
- Six requested tours: Giza Pyramids, Saqqara, Grand Egyptian Museum, Fayoum, Alexandria, Cairo Daily Tour (Mohamed Ali Citadel, Hanging Church, Khan el-Khalili).
- Five requested vehicles: Mercedes Sedan, Mercedes Van, Toyota Hiace, Nissan Sentra, Toyota Corolla.
- Uploaded Glory Home logo.
- Two WhatsApp contact numbers with a selector in the booking form.
- Tour and vehicle inquiry links prefill the WhatsApp form.

## Publish with GitHub Pages
1. Create/open the GitHub repository for this website.
2. Upload all files and the `assets` folder (keep the same structure).
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)` → Save.

## Before going live
- Confirm both WhatsApp numbers and the contact person for each.
- Review the destination and vehicle photos. Current photos are remotely loaded from Unsplash and are visual placeholders; replace with your own/approved photos when available.
- Confirm all tour descriptions, routes, operating details, fleet availability, and any prices before publishing.
- The booking form sends inquiries only; it does not take payment or confirm a booking automatically.
